# Osservatorio Grandi Investitori

Dati del cruscotto con i portafogli 13F dei superinvestitori (fonte: Dataroma e SEC; prezzi Yahoo Finanza).
Il file `data/dati.json` viene aggiornato automaticamente ogni mattina alle 7:24 (ora italiana).
Il file per il monitor scarica da qui i dati nuovi: non modificare né rinominare questo archivio.
